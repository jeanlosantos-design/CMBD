** Projeto banco de dados de um sistema de vendas **


este projeto foi desensvolvido para criação de um banco de dados relacional 
aplicado a um sistema de Venadas


A primeira parte do projeto comtém a repressentação do modelo do DB através de
um diagrama de entidade-relacionamente.


Criação das Tabelas:
  - CLIENTES;
  - PEODUTOS;
  - PEDIDOS
  - FORNECEDOES;
  - COMPRAS.

o projeto possui um  código fonte revisado e documentado.
